BatchBarcode Privacy

BatchBarcode is designed to process barcode jobs in the browser, with only aggregate workflow metrics sent to analytics.

Local processing

  • Barcode generation runs locally in your browser.
  • CSV and XLSX parsing runs locally in your browser.
  • Barcode values are not uploaded to BatchBarcode.
  • File names, worksheet names and mapped column names are not intentionally sent to analytics.

Do not upload sensitive data as a general safety practice, but the tool does not need your source file on a server to generate labels.

Aggregate analytics

Google Analytics 4 is used for aggregate usage metrics so the workflow can be improved. Current events record low-cardinality details similar to:

  • barcode type
  • input source
  • batch size bucket
  • generation success or failure
  • export type
  • print intent

Free-text fields in the larger-batch interest form are not sent to GA4. The optional email is currently used only to record whether an address was provided; it is not sent or stored by this static release.
