Barcode Generator Help & FAQ

Practical answers for turning text, CSV or Excel rows into barcode images and printable A4 or Letter label sheets.

Getting started

Does BatchBarcode upload my barcode data?

No. Barcode rendering, spreadsheet parsing and file export run locally in your browser. Barcode values, file names and mapped columns are not sent to BatchBarcode.

Which barcode format should I choose?

Use Code 128 for compact internal IDs, QR codes for URLs and phone scanning, Data Matrix for compact part labels, and PDF417 for printable codes that hold more text. EAN-13 and UPC-A are for retail product numbers.

Can I generate more than one barcode at a time?

Yes. Open Batch & A4 PDF on any format page, enter one value per line, or import a CSV or Excel file. The current browser limit is 100 usable rows per batch.

Why is the batch limited to 100 barcodes?

The limit keeps rendering, previews and PDF creation responsive on ordinary devices. Split larger jobs into batches of 100; no extra rows are silently discarded.

CSV, Excel and file output

What CSV and Excel files are supported?

The batch tool accepts CSV and .xlsx files up to 5 MB. Excel import reads the first worksheet, then lets you map barcode value, label text and extra text columns.

Can I create an A4 or Letter barcode-label PDF?

Yes. Select Batch & A4 PDF, choose A4 or Letter, adjust rows, columns, margins and gaps, then use Download PDF. The same layout is used for browser printing.

Should I download PDF or PNG ZIP?

Use PDF when you need a ready-to-print label sheet. Use PNG ZIP when another application, document or label workflow needs separate image files.

Are my label-layout settings saved?

Yes. The current A4 or Letter layout preferences are saved in this browser. They are not synchronized to another browser or device.

Printing and scanning

Why does a barcode scan on screen but fail after printing?

The printed code may be too small, blurred, clipped or surrounded by too little white space. Print at 100% scale, avoid fit-to-page, and test the final printer, paper and scanner.

What is a barcode quiet zone?

The quiet zone is the blank space around a barcode. A scanner uses it to separate the symbol from nearby text, borders and graphics, so do not crop it away.

Should I use “Fit to page” when printing labels?

No. Start with 100% or actual-size printing. Fit-to-page can resize bar widths and label spacing, causing poor scans or misalignment with label stock.

How should I test a label before a production run?

Print one page using the final printer and paper, then scan every label with the actual phone or scanner used in the workflow. Change only one setting at a time if a scan fails.

Format-specific questions

Can BatchBarcode calculate an EAN-13 check digit?

The EAN-13 generator accepts 12 digits and lets the barcode library calculate the final digit. If you enter all 13 digits, the existing check digit must be valid.

Can BatchBarcode calculate a UPC-A check digit?

The UPC-A generator accepts 11 digits and calculates the twelfth digit. A 12-digit value is accepted only when its check digit is valid.

What is the difference between PDF417 and MicroPDF417?

PDF417 supports more data and flexible symbol shapes. MicroPDF417 is smaller but has tighter capacity limits, so use it only when space is limited and the encoded value is short enough.
