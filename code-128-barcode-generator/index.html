This free online Code 128 barcode generator creates a scannable linear barcode from text, SKUs, order numbers, asset IDs, and inventory references. It includes the human-readable value under the bars for easier label checks.

When to use Code 128

  • Inventory and warehouse labels with short alphanumeric IDs.

Code 128 FAQ

Can I print a batch of Code 128 labels on A4 paper?

Yes. Select Batch & A4 PDF above, enter one value per line or import a spreadsheet, then choose the A4 label layout.

What data works well in Code 128?

Code 128 is best for compact letters, numbers and common punctuation used in SKUs, asset IDs and order references. Use QR code for long text, URLs or broader character support.

Why is my Code 128 barcode very wide?

Long values and a high scale create wider bars. Shorten the encoded value or lower the scale, then test the printed result with the final scanner.
